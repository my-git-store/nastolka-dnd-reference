# Справочник D&D · Настолка

Русский бестиарий и книга заклинаний по открытым правилам D&D 2024, SRD 5.2.1. В каталоге 336 существ и 339 заклинаний. Поиск понимает русские и английские названия, а также прежние варианты перевода названий существ. Заклинания можно отфильтровать по уровню, включая заговоры.

## Локальный запуск

Требуется Node.js версии 22.12 или новее.

```sh
npm ci
npm run dev
```

Откройте адрес, указанный Vite. Главная страница ведёт в бестиарий (`/reference/monsters`) и книгу заклинаний (`/reference/spells`). Подробности открываются в окне поверх каталога. Клавиша Escape закрывает окно и возвращает фокус к выбранной карточке.

Внизу каждой страницы раскройте «Книга и источники», чтобы открыть [«Книгу игрока 2024» в русском переводе Koroz](src/assets/books/players-handbook-2024-ru.pdf). PDF входит в сборку и открывается в отдельной вкладке.

## Проверка и сборка

```sh
npm test
npm run typecheck
npm run build
npm run preview
```

В каталоге `dist/` находится готовый статический сайт. На хостинге настройте возврат `index.html` для маршрутов приложения, чтобы прямые ссылки на разделы открывались после обновления страницы. Изображение, шрифты и каталоги входят в сборку. Для работы справочника серверное API не требуется.

## Данные и оформление

Каталоги находятся в `src/modules/public/reference/data/`. Команда `npm run reference:sync -- --check` сверяет их с закреплённой версией исходного перевода с учётом редакторских поправок. Команда `npm run reference:sync` пересобирает оба JSON-файла. Для сверки и обновления нужен доступ к GitHub.

Оригинал SRD 5.2.1 подготовлен Wizards of the Coast, русский перевод — Petr Radilov (OmnisGM). Материалы правил и перевод распространяются по CC BY 4.0. Источники и редакторские изменения перечислены в [атрибуции SRD](public/licenses/srd-5.2.1.txt).

В основе оформления — тема листа персонажа «Настолка» из проекта [dnd5v](https://github.com/my-git-store/dnd5v/tree/22425b1). Палитра, настройки Naive UI и стили находятся в `src/styles/`, карта-пергамент — в `src/assets/`. Шрифты поставляются вместе с приложением. Условия использования — [Lora](public/licenses/lora-OFL.txt) и [Plus Jakarta Sans](public/licenses/plus-jakarta-sans-OFL.txt).
